# SIGN TRAINER デザイン仕様 — v1.5.34

## 原則
- 小学生でも迷わず使え、中高生にも幼く見えないスポーツUI。
- 1画面1目的。主操作と状態を視覚的に分離する。
- スマホ375–430pxを基準にし、PCは横方向へ情報を拡張する。
- Deep Navy + Greenをブランド基調とする。

## ブランド
- ロゴ: 既存野球アイコン + `SIGN TRAINER`
- 白背景では `SIGN`を濃紺、`TRAINER`をグリーン
- キャッチコピー: **「野球のサインを、チームの力に。」**

## 共通ヘッダ
- LP・練習・管理画面でブランド表現を統一。
- SYSTEM / チーム管理: PCは左サイドメニュー、スマホは右上ハンバーガー。
- 練習: スマホメニューはヘッダ外の全画面最前面ドロワー。

## チーム管理
- ダッシュボードは主要カードを上、補助情報を下へ。
- PC下部は「SYSTEMお知らせ」と「最近のアクティビティ」を左右2分割。
- 最近のアクティビティはProバッジを明示。
- お知らせ種別は色・ラベルの両方で識別する。

## サイングループ
- 登録モーダルでは具体的な使用例をカードで提示。
- 使用例カードを押すと名称・説明へ反映する。
- 例: バッティング、守備（ランナーなし）、守備（2塁ランナーあり）、ピッチング、走塁。
- 説明動画がある場合はYouTube標準サムネイルを表示する。

## サイン管理
- 「すべてのサイン」をデフォルト選択。
- グループ選択 + 名称検索 + 一覧。
- 動画はサムネイル自体をクリックして確認し、冗長な「確認」ボタンは置かない。
- Free / Plus / Proのロック機能には必要プラン名のバッジを表示する。

## 練習履歴・分析
- 履歴には分析サマリーだけを置く。
- Proの詳細分析は独立ページ。
- 正答率は数値だけでなくリング・バー等の視覚表現を併用する。

## レスポンシブ
- 一覧カードはスマホ左右余白を確保し、外枠と重ならない。
- PCの管理画面はサイドバーを維持する。
- モバイルドロワーは本文より高いstacking contextで表示する。


## v1.5.30 練習・サイン管理UI

- 練習トップの見出し前にTEAMラベルとチーム名を大きく表示する。
- PCクイズは管理画面と同じ広いコンテンツ幅を使い、動画を主役として表示する。
- サイン一覧の編集操作の横に ↑ / ↓ の並べ替えボタンを表示し、端のサインでは該当方向をdisabledにする。

## v1.5.31 練習ページ

- PCは管理画面と同様に横幅を活かし、最大1120pxのコンテンツ面を使用する。
- 「練習チーム」ラベルの下にチーム名を大きく太字で表示し、練習トップ・履歴・分析で共通化する。
- サイングループカードはPCで2列、スマホで1列。説明動画サムネイルを主役として見せる。
- グループの補助操作と練習開始操作は横並びにせず、上下に積んで押しやすさを優先する。



## v1.5.32 PCクイズ画面

PCでは動画と質問・回答操作を左右2カラムで表示し、動画再生中でも「答えを見る」「もう一度見る」「この問題を飛ばす」がファーストビュー内に残るようにします。スマホは従来どおり縦並びです。


## v1.5.33 結果共有UI

- 練習結果画面にSHAREカードを追加する。FreeではPlus機能であることを明示し、Plus / Proでは「文章で共有」を表示する。
- Proでは「画像カードで共有」も表示し、文章共有と主従が分かる2ボタン構成にする。
- 成績分析ページにもPro向けの文章共有・画像カード共有を配置する。
- 共有カードには「具体的なサイン内容・動画URLを含めない」旨を明示し、共有状態をaria-liveで通知する。
