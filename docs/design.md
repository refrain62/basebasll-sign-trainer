# SIGN TRAINER デザイン仕様 v2

この文書は、会話内で作成したLP・スマートフォン画面のデザイン案を、実装へ落とし込むための基準です。

## 1. デザイン原則

- 小学生でも説明なしで操作できることを最優先にする。
- 中高生が使っても幼く見えない「現代的なスポーツツール」にする。
- LPは写真とコピーで世界観を作り、練習開始後は情報量を落として集中させる。
- 1画面1目的。主操作を常に1つ明確にする。
- 色だけで意味を伝えず、文字・記号・形も併用する。
- スマートフォン 375–430px を基準にし、PCでは情報量を横方向へ拡張する。

## 2. ブランドトーン

- Deep Navy: `#031727` / `#05233b`
- Navy: `#082844`
- Green: `#07834c` / `#079653`
- Red: `#ef2f36`
- Orange: `#ff6d2f`（限定的に使用）
- Background: `#f4f8fa`
- 見出し: 太く、短く、コントラストを高くする。
- ヒーローコピーのみ明朝系を混ぜ、先に作成したスポーツ広告風の印象を再現する。

## 3. LP

### 3.1 ヘッダー

- 白背景。
- 左に野球ボールロゴ + `SIGN TRAINER`。
- PCは「特徴 / 使い方 / こんな方に / よくある質問 / サンプルを試す」。
- スマホはハンバーガーメニュー。

### 3.2 Hero

先に作成したデザイン案の最重要部分。

- 監督・コーチがサインを出している写真を大きく使う。
- 濃紺のグラデーションを重ね、白文字の可読性を確保する。
- コピー:
  - `見て、覚えて、迷わず動く。`
  - `チームのサインを動画でくり返し練習。`
- `迷わず動く。` の下へグリーンの手描き風ライン。
- 主CTA: `サンプルチームで試す`。
- 補足: `インストール不要・すぐに使えます`。
- PCでは写真を右側に寄せ、左のコピー領域を確保する。
- スマホでは写真を全面背景にし、下側にコピーとCTAを重ねる。

### 3.3 特徴4項目

Hero直下の白いストリップ。

1. 動画でわかる
2. くり返し練習
3. チームの成長
4. すぐに使える

PCは4列、スマホは2×2（狭い端末では1列）。

### 3.4 なぜサインの練習が大切？

- 左: 説明文と3つのチェックポイント。
- 右: 野球の空気感があるビジュアル。
- 見出し下へグリーンのライン。
- 「ひとつのサインがチームを動かす。」を手書き風に表示。

### 3.5 使い方はかんたん3ステップ

先に作成したLP案と同じく、スマートフォンモックを3台並べる。

1. 練習設定
2. 動画を見て答える
3. 正解を確認

PCでは横並び、スマホでは縦並び。

### 3.6 こんなチーム・選手におすすめ

4カード。

- チーム全員でサインを統一したい
- 効率よくサインを覚えたい
- 楽しくくり返し練習したい
- 練習時間をもっと有効に使いたい

### 3.7 LINE導線

濃紺のカードとしてLP内で独立させる。

`LINE URL → 合言葉 → 10問開始`

の3ステップを表示する。

### 3.8 FAQ / 最終CTA / Footer

- FAQはアコーディオン。
- 最終CTAは白カード + グリーンボタン。
- Footerは濃紺背景。

## 4. 合言葉画面

- 白を主体とした画面。
- 上部にブランド。
- 中央に鍵アイコン。
- `チームのサイン練習`
- `合言葉を入力してください`
- 合言葉はパスワード欄にせず、通常のテキスト入力とする。日本語IME（ひらがな・カタカナ・漢字）を優先する。
- 主CTAはグリーンで `練習をはじめる`。
- 約30日認証保持を薄いグリーンの案内カードで表示。
- エラーは赤いカードで表示するが、責める文言にしない。

## 5. 練習設定

- 白背景。
- タイトル `サイン練習`。
- ボールロゴを大きく配置。
- 選択肢の優先順位:
  1. 10問ではじめる（グリーン・おすすめ）
  2. 5問ではじめる
  3. 全てのサイン
- 下部に3つの練習ポイント。
- 認証解除は最下部の小さなテキストリンク。

## 6. 問題画面

LPとは明確に世界観を切り替える。

- 背景: Deep Navy。
- ヘッダー: `× 終了 / 問題 n / total`。
- 直下に細い進捗バー。
- 動画を画面幅いっぱいに近いサイズで表示。
- 再生前は動画カバー + 大きな再生ボタン。
- `このサインは何でしょう？` を大きく中央表示。
- 主CTA: `答えを見る`（Green）。
- 補助: `もう一度見る`（透明+白枠）。
- 最下部: `この問題を飛ばす`。

## 7. 動画状態

### 読み込み中

- スピナー。
- `動画を準備しています…`。
- `数秒かかる場合があります`。

### エラー

- 赤い `!`。
- `動画を読み込めませんでした`。
- `再試行する` を主ボタン。
- `この問題を飛ばす` を補助ボタン。

## 8. 正解 / 自己採点

- 上部だけ濃紺ヘッダーを維持。
- 本文は白〜薄いグレー。
- 正解カードは薄いグリーン。
- `正解は…` + サイン名を大きく表示。
- `○ 正解した` はGreen全面。
- `× 間違えた` は白背景 + Red枠。
- 選択肢形式にはしない。

## 9. 採点後の自動遷移

- 採点後は濃紺の短いトランジション画面を表示。
- 正解ならチェック、間違いなら×。
- `つぎの問題へ進みます`。
- 約1.3秒後に自動遷移。
- その間だけ `採点を変更` が可能。

## 10. 結果

- 白画面。
- `練習結果`。
- 円形の正答率表示。
- 正解 / 不正解 / 時間を3列で表示。
- 間違えたサインの概要を表示。
- 最優先CTA: `間違えたN問をもう一度`。
- 補助: `もう一度10問`。
- 最下部: `問題数を選び直す`。

## 11. 間違えた問題一覧

結果から直接クイズ開始せず、一覧画面を1枚挟む。

- `間違えた問題（N問）`
- サイン名を一覧表示。
- `このN問で練習する` を主CTA。

これにより、ユーザーは何を復習するか理解した上で再開できる。

## 12. 確認ダイアログ

### 練習終了

- `練習を終了しますか？`
- `ここまでの進み具合は保存されません。`
- Red: `終了する`
- White: `キャンセル`

### 認証解除

- `この端末の認証を解除しますか？`
- 次回は合言葉が必要になる旨を表示。

## 13. 実装上のレスポンシブ基準

- 320px: 最低対応幅
- 375–430px: 最優先
- 680px以下: スマホ専用レイアウト
- 900px以下: タブレット調整
- 1180px: LP最大コンテンツ幅
- アプリ本体: PC時は最大430px程度の操作領域へ集約。合言葉画面のみ、PCではLPの写真トーンを踏襲した2カラム構成とする

## チーム利用の正式導線

LPのCTAはサンプルチームの体験ページへ遷移する。正式利用では、チーム登録後にチーム専用ページとURLを発行し、監督・コーチがLINE等でそのURLを共有する。メンバーは共有URLからアクセスし、チームの合言葉で認証して練習する。


## 15. 管理者アカウント / チーム登録（build 70）

- LPの主CTAからGoogle / LINE認証を選び、そのままチーム登録へ進める。
- 認証前に管理者パスワードを要求しない。認証後は「チーム名」「選手用合言葉」の2項目に集中させる。
- チーム管理画面では「オーナー」「管理者」を視覚的に区別する。
- 管理者追加とオーナー交代はワンタイムリンクを使い、リンク発行・コピー・LINE送信を同じモーダル内で完結させる。
- オーナーは権限移譲前に退会できない。通常管理者は自分でチームから退会できる。
- スマホでは管理者カードとアクションを縦配置し、44px以上のタップ領域を確保する。
