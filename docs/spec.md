# SIGN TRAINER 仕様書 — v1.5.32 / build 101

最終更新: 2026-09-26

## 1. 目的

野球チーム固有のサインを、実際のYouTube動画を使って反復練習するWeb / PWA。管理者はチームごとのサインを整理し、選手は合言葉で参加して動画クイズを練習する。

## 2. ユーザー区分

### 選手
- `/t/{teamId}`
- チーム合言葉で認証
- サイングループ選択、動画クイズ、自己採点、間違い復習
- 練習履歴は端末の`localStorage`へ最大50件保存
- Proでは正答率・苦手分析の詳細ページを利用可能

### チーム管理者
- `/account`でGoogle / LINE OAuth認証
- `/t/{teamId}/admin`でチーム・グループ・サイン・動画・共有・管理者を管理
- メイン管理者は1名
- Plus / Proではサブ管理者を最大5名追加可能
- チーム退会はメイン管理者のみ。サブ管理者は自分だけ管理者から抜けることが可能
- 退会は論理削除。SYSTEM管理から復活可能

### SYSTEM管理者
- `/admin`
- Cloudflare Access + `SYSTEM_ADMIN_SECRET`の二重認証
- チーム登録・編集・利用停止・退会済み化・復活
- Free / Plus / Proの手動変更
- SYSTEMお知らせの登録・編集・公開

## 3. プラン

| 機能 | Free | Plus | Pro |
| --- | :---: | :---: | :---: |
| 基本サイン登録・練習 | ✓ | ✓ | ✓ |
| Google / LINE OAuth | ✓ | ✓ | ✓ |
| サイングループ | 1 | 複数 | 複数 |
| 1サインの動画 | 1本 | 複数 | 複数 |
| 動画プレビュー開始位置指定 | - | ✓ | ✓ |
| メイン管理者 | 1名 | 1名 | 1名 |
| サブ管理者 | - | 最大5名 | 最大5名 |
| 正答率・苦手分析 | - | - | ✓ |
| グループ／サイン／動画別分析 | - | - | ✓ |
| 最近のアクティビティ／監査ログ | - | - | ✓ |

Plus / Proは現在、特定チームへの限定提供。一般申し込み・オンライン課金・Stripe Checkoutは未実装。SYSTEM管理者だけが手動でプランを変更する。

プランダウン時も既存グループ・複数動画・サブ管理者データは物理削除しない。現在プランで許可されない新規追加・アクセスだけを制限する。

## 4. サイングループ

- グループ名、説明、説明用YouTube動画、並び順、使用状態を管理
- グループ説明動画はYouTube標準サムネイルを表示。秒指定は持たない
- 登録画面では具体的な使用例を提示し、選択すると名前・説明へ反映
  - バッティングサイン
  - 守備サイン（ランナーなし）
  - 守備サイン（2塁ランナーあり）
  - ピッチングサイン
  - 走塁サイン
- Freeは1グループ、Plus / Proは複数グループ

## 5. サイン・動画

- サインはグループに所属可能
- サイン管理は「すべてのサイン」をデフォルト表示し、グループ・名称で絞り込み可能
- YouTube動画は標準サムネイルを表示し、サムネイルクリックでプレビュー
- Freeは1サイン1動画
- Plus / Proは1サイン複数動画、用途コメント、プレビュー開始位置を利用可能
- 複数動画を使う練習では、出題回数・最近の利用状況を見て動画パターンの偏りを抑える

## 6. 練習

- グループ選択 → 問題数選択 → 動画再生 → 自己採点
- サインデータが0件の場合はエラーにせず、管理者の登録待ち画面を表示
- 履歴は最大50件、10件ずつページング
- 履歴画面の分析はサマリーのみ
- Proの詳細分析は専用「成績分析」ページで表示
  - 累計／直近正答率
  - グループ別
  - サイン別
  - 動画パターン別
  - 苦手サイン（原則3回答以上）
  - 苦手サインだけ再練習

## 7. 管理UI

- PCのSYSTEM管理・チーム管理は左サイドメニュー
- スマホは右上ハンバーガーから全画面メニュー
- お知らせはダッシュボード直下の主要メニュー
- チーム管理ダッシュボード下部はPCで「SYSTEMお知らせ / 最近のアクティビティ」の2カラム、スマホで縦並び
- 最近のアクティビティはProのみ

## 8. お知らせ

SYSTEM管理で登録した公開中かつ掲載期間内のお知らせをチーム側へ表示する。表示優先度は、固定案内 → 重要 → メンテナンス → その他。

## 9. チーム状態

- `active`: 利用中
- `suspended`: SYSTEM管理による利用停止
- `deleted`: 退会済み（論理削除）

退会済みでも関連データを保持し、SYSTEM管理から復活すると`active`へ戻す。退会・復活は監査ログへ記録する。

## 10. 認証・セキュリティ

- 選手合言葉、旧管理パスワードはPBKDF2-SHA256 + pepper
- 管理OAuthのaccess token / refresh tokenは保存しない
- 管理CookieはHttpOnly / SameSite、remote本番ではSecure
- 管理系状態変更APIはOrigin / Fetch MetadataでCSRF防御
- SYSTEM管理remote環境はCloudflare Access必須
- 秘密値・合言葉・パスワードを監査ログへ保存しない

## 11. データ保存

D1: チーム、サイン、動画、グループ、管理者、プラン、Entitlement、お知らせ、監査ログ等。

端末localStorageのみ: 選手の回答、正答率、練習時間、練習履歴、分析元データ。別端末には同期しない。

## v1.5.30 UI / 操作仕様

- 練習トップには認証済みチーム名を表示する。
- 練習メニューにはLPへの「トップページ」項目を置かず、「練習ページ」を先頭にする。
- PCのクイズ動画領域は最大1120pxまで利用し、スマホでは100%幅に追従する。
- サインの並び順は編集モーダルの数値入力ではなく、一覧の上下ボタンで変更する。上下操作は現在表示中のグループ（「すべてのサイン」を含む）の並びを基準にする。

## v1.5.31 練習画面レイアウト仕様

- 練習トップ・練習履歴・成績分析・履歴詳細には、認証済みチーム名を共通の「練習チーム」見出しとして表示する。
- PCでは練習系ページのコンテンツ領域を最大1120pxまで利用する。
- PCのサイングループ一覧は2列を基本とし、説明動画サムネイルを大きく見せる。
- サイングループカードの「説明を見る」と「このグループで練習する」は上下配置とし、誤タップを減らす。
- スマホでは1列表示を維持し、チーム名は30px程度で明確に表示する。



## v1.5.32 PCクイズ表示

画面幅900px以上では、クイズを動画左・質問/回答操作右の2カラムにします。動画サイズはビューポート高も上限にして、回答操作が画面下へ押し出されないことを優先します。900px未満では従来の縦レイアウトです。
