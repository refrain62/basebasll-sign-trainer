# チーム管理者の権限設計

SIGN TRAINER のチーム管理者は、共有パスワードではなく Google / LINE で本人認証したアカウント単位で管理します。

## 人数上限

1チームあたりの構成は次のとおりです。

- メイン管理者: 1名
- サブ管理者: 最大5名
- 合計: 最大6名

内部DBでは互換性維持のため `team_admin_memberships.role` に `owner` / `admin` を使用しますが、UI上はそれぞれ「メイン管理者」「サブ管理者」と表示します。

## メイン管理者

メイン管理者はチームごとに必ず1名です。サブ管理者の招待・削除、メイン管理者の交代、旧共有管理者パスワードの無効化など、権限管理に関する操作を行えます。

メイン管理者はそのままチームから退会できません。先に登録済みサブ管理者へ権限を移すか、新しいメイン管理者へのワンタイム招待を完了する必要があります。

## サブ管理者

サブ管理者は最大5名です。各自が自分のGoogle / LINEアカウントで管理画面へ入り、サイン・グループ・動画・チーム設定などの日常運用を行えます。

サブ管理者は自分でチームから退会できます。メイン管理者はサブ管理者をチームから外すこともできます。

## 上限の強制

UIでボタンを無効化するだけではなく、Service / Repositoryでも上限を強制します。

- 現在のサブ管理者 + 承認待ちのサブ管理者招待が5枠に達した場合、新しい招待リンクは発行できません。
- 招待発行後に別の招待が先に承認された場合でも、招待承認時に再度上限を検証します。
- D1への追加SQLにも人数条件を含め、同時承認で6人目が追加されないようにします。
- メイン管理者交代で旧メイン管理者がサブ管理者として残る場合も、5名上限を超えないことを確認します。

## 既存データが5名を超えている場合

以前のバージョンですでに6名以上のサブ管理者が登録されている場合、自動削除は行いません。新しいサブ管理者の追加を停止し、メイン管理者が不要なサブ管理者を外して5名以下へ整理します。

データを自動削除しないのは、意図しない権限喪失を防ぐためです。
